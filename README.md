# RestaurantReviewApp

飲食店の検索・レビュー登録・編集・削除を行うWebアプリケーションです。

Java / Spring Bootを使用して開発しました。

## 概要

飲食店の情報を確認し、店舗に対するレビューを登録・編集・削除できるWebアプリケーションです。

Webアプリケーション開発の基本的な流れを理解することを目的として、画面遷移、フォーム入力、バリデーション、データの登録・更新・削除などを実装しています。

## 主な機能

- 飲食店一覧表示
- 飲食店検索
- レビュー一覧表示
- レビュー登録
- レビュー登録確認
- レビュー編集
- レビュー編集確認
- レビュー削除
- レビュー削除確認
- 入力値バリデーション
- エラー画面表示

## アプリケーション構成

主に以下の役割に分けて実装しています。

- **Controller**
  - HTTPリクエストを受け取り、画面遷移を制御
- **Form**
  - 画面から入力されたデータを保持
- **Service**
  - アプリケーションの処理を担当
- **Repository**
  - データアクセスを担当
- **Template**
  - Thymeleafを使用した画面表示
- **CSS**
  - 画面のレイアウト・デザインを担当

## 工夫した点

### 入力値のバリデーション

ユーザーが入力した内容をチェックし、不正な入力をそのまま処理しないようにバリデーションを実装しています。

### 確認画面の実装

レビューの登録・編集・削除を実行する前に確認画面を設けています。

ユーザーが操作内容を確認してから処理を実行できるようにしました。

### 役割ごとのクラス分割

Controller・Service・Repositoryなど、処理の役割を分けることで、コードの見通しや保守性を意識して実装しました。

### Git / GitHubによるソースコード管理

Gitを使用して開発中のソースコードを管理し、GitHubで公開しています。
